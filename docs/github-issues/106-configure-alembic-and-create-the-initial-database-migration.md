# [M1-06] Configure Alembic and create the initial database migration

**Milestone:** M1 – Backend Foundation · **Priority:** High · **Estimated effort:** 2–4 hours

## 1. Objective
Set up Alembic so the database schema is created and changed only through versioned migrations, and create the first migration for all four tables.

## 2. Background
Migrations let every environment (laptop, CI, Cloud SQL) reach the same schema in a controlled, reviewable way. From now on `database/init.sql` is reference only.

## 3. Learning objectives
- What a migration is and why schemas need version control
- `alembic revision --autogenerate` and why you must review its output
- `upgrade` / `downgrade`

## 4. Prerequisites
- M1-05 merged

## 5. Tasks
- [ ] Run `alembic init alembic` inside `backend/`
- [ ] Configure `alembic/env.py` to read `DATABASE_URL` from settings and use `Base.metadata`
- [ ] Autogenerate `initial schema` migration and review it line by line
- [ ] Verify `alembic upgrade head` then `alembic downgrade base` both work
- [ ] Update `database/README.md` with migration commands

## 6. Technical guidance
Autogenerate is a draft, not the truth. Check it includes every CHECK and UNIQUE constraint; add any it missed by hand. Never edit a migration that has been merged; create a new one instead.

## 7. Acceptance criteria
- [ ] `alembic upgrade head` creates all four tables with constraints and indexes
- [ ] `alembic downgrade base` removes them cleanly
- [ ] Resulting schema matches `database/init.sql` (compare with `\d+ table` in psql)

## 8. Testing requirements
- Run upgrade/downgrade/upgrade on an empty database and paste the output
- `psql \d order_items` output attached to the PR

## 9. Expected deliverables
- `backend/alembic.ini`, `backend/alembic/`, first migration file

## 10. Definition of Done
- [ ] All acceptance criteria met
- [ ] Tests written and passing (paste the real command output in the PR)
- [ ] Relevant documentation updated
- [ ] PR references this issue and is approved by another participant
- [ ] CI checks pass (from M5 onward)
- [ ] Merged into `develop`
- [ ] Card moved to **Done**
