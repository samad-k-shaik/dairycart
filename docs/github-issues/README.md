# GitHub Issue Specifications

Markdown copies of the GitHub Issues. Each file has the same content as its GitHub issue (the `issue-meta` comment at the top holds title, labels and milestone and is not part of the issue body).

When an issue is edited on GitHub, update its file here in the same PR (or vice versa).
