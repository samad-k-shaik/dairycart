# Feature - Admin product management

**GitHub issue:** #86 · **Milestone:** M8 – Ordering, Subscriptions and Delivery Operations

### 1. Objective

## Feature: Admin product management
- Admin can **add** a new product (name, size, price, availability) from the admin Products page.
- Admin can **edit** an existing product's details (name, size, price, availability) instead of deleting and re-creating it.
- Admin can **delete** a product only if it was never ordered; otherwise they're asked to mark it unavailable.
- Build both frontend (admin UI) and backend (APIs to create, update and delete products under `/api/v1/admin/products`).
